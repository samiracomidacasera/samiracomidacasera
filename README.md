# 🍲 Samira Comida Casera Marroquí - Torremolinos

Sitio web oficial y menú interactivo de **Samira Comida Para Llevar**, restaurante de auténtica comida casera tradicional marroquí en Torremolinos (Málaga, España).

---

## ✨ Características Principales

- 🌐 **Soporte Multilingüe**: Español (ES) e Inglés (EN) con selector dinámico.
- 🥘 **Menú Digital Completo**: Catálogo exhaustivo de platos auténticos (Tajines, Cuscús, Pastelas, Carnes, Pescados, Sopas y Postres) con fotografías, precios y descripciones.
- 📱 **Diseño 100% Responsivo**: Experiencia fluida y adaptada para móviles, tablets y escritorio.
- 📍 **Información de Contacto y Pedidos**: Acceso directo a llamadas, WhatsApp, servicio para llevar y Uber Eats.
- 🗺️ **Ubicación Interactiva**: Mapa integrado con la dirección física (C. Río Aranda, 11, Torremolinos).
- 🎨 **Diseño e Identidad Cultural**: Paleta de colores inspirada en la artesanía marroquí (verde esmeralda, acentos dorados y patrones zellige).

---

## 🚀 Tecnologías Utilizadas

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones**: [Framer Motion](https://www.framer-motion.dev/)
- **Iconos**: [Lucide React](https://lucide.dev/)

---

## 💻 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Aminedrissi12/samiracomidacasera.git
   cd samiracomidacasera
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. Abrir en el navegador: [http://localhost:3000](http://localhost:3000)
